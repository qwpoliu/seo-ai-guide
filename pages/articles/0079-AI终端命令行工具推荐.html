AI终端命令行工具推荐

你是不是也遇到过这种情况：在终端里苦想一个命令怎么写，或者忘了某个参数怎么用，不得不切出去百度或问ChatGPT？过去我们总把终端和AI当成两回事，一边是黑乎乎的窗口，一边是聊天的对话框。但现在不一样了——AI直接搬进了你的命令行。今天我就来推荐几款特别实用的AI终端命令行工具，让你在终端里就能和AI聊起来，写命令、查资料、甚至写代码都效率翻倍。

Shell GPT — 把ChatGPT塞进终端

第一个要推荐的是Shell GPT（命令行简称`sgpt`）。这玩意儿本质上就是把OpenAI的GPT模型直接拉到你的终端里，你用管道或者直接输入问题，它就能给你回答。最常用的是用它来生成命令：比如你想找一个包含所有子目录里大于100MB的文件的命令，直接输入`sgpt "find all files larger than 100MB in subdirectories"`，它就会甩给你一行`find . -type f -size +100000k`，还附带解释。更爽的是它还能直接执行生成出来的命令，只需要加个`--execute`参数，它会先问你是否要执行，确认后就直接跑起来了。对于Linux和macOS用户来说，这简直就是救命工具，再也不用记那些稀奇古怪的awk、sed语法了。

安装也简单：`pip install shell-gpt`，然后设置你的OpenAI API Key就能用。如果你觉得每次还要手动给API Key很麻烦，可以写进环境变量里。

GitHub Copilot CLI — 让AI帮你敲命令和查代码

如果你已经是GitHub Copilot的付费用户，那你一定不能错过它的官方CLI工具——gh copilot。这个工具直接集成在GitHub CLI（`gh`）里，装好`gh`之后用`gh extension install github/gh-copilot`就能装上。它有两个核心模式：`gh copilot explain`和`gh copilot suggest`。

`explain`模式特别适合你看到一条陌生的命令时用，比如你看到别人脚本里写了个`sed -i 's/old/new/g' file`，你不懂，直接`gh copilot explain "sed -i 's/old/new/g' file"`，它会详细解释每个参数是什么意思，还会告诉你安全注意事项。`suggest`模式则是反过来，你描述你要做的事，它给你推荐命令。比如输入`gh copilot suggest "find all files modified in the last 7 days"`，它就会给出`find . -type f -mtime -7`并附带简短说明。而且它支持交互式对话，你可以追问“那帮我用压缩打包这些文件”，它会基于之前的上下文继续给出命令。对于经常要在终端里调试的人来说，这工具就是随身AI导师。

aichat — 多模型通用的聊天CLI

如果你不想被绑死在OpenAI一家，aichat是个很棒的替代品。它是一个用Rust写的轻量级CLI工具，支持OpenAI、Claude、Gemini、甚至本地模型比如Ollama。安装后你只要配置好API Key，就可以直接在终端里和AI聊天。它的用法超级简单：`aichat "写一段Python脚本，读取CSV文件并统计每列的空值数量"`，然后它就会给你输出代码，还带注释。更贴心的是支持`-r`参数直接运行生成的代码，或者`-c`参数把结果复制到剪贴板。

aichat还有一个杀手级功能：它可以接入系统命令的管道输入。比如你用`cat error.log | aichat "从这些错误日志里找出所有连接超时的记录，并按时间排序"`，它就能直接分析你传过去的日志内容，返回整理后的结果。对于运维和数据分析场景，这个管道能力简直太香了。而且由于它支持多模型，你可以根据自己的需求切换更便宜或者更快的模型，控制成本很灵活。

llm — 大模型命令行瑞士军刀

由Simon Willison开发的llm工具，是另一个值得安装的通用CLI。它提供了一个非常简洁的接口，核心命令就是`llm`后面接问题。但它真正强的地方在于插件系统：你能通过插件接入各种模型，包括OpenAI、Anthropic、Google、Llama、Mistral等，甚至是本地的LLaMA.cpp。比如你想让AI帮你解释一个复杂的命令行，直接`llm "explain: ssh -L 8080:localhost:80 user@host"`，它就会返回详细解释。还能用`-m`参数指定模型，比如`llm -m claude-3-haiku "写个bash脚本备份目录"`。

`llm`另一个让我经常用的功能是对话历史。它默认会保存每次对话的日志，你可以用`llm logs`查看，或者用`llm -c`继续上一次的对话。如果你想用AI来写笔记摘要、翻译文章、甚至写代码，只需要`llm < text.txt`把文件内容喂给它。配合终端里的别名，比如`alias a=llm`，几乎可以无缝替代掉那些需要开浏览器才能用的AI。安装的话，用`pip install llm`就行，之后`llm keys set openai`设置API Key。

其他值得一试的工具

除了上面几个主力，还有一些小而美的AI终端工具也值得关注。比如Claude CLI（Anthropic官方出的），安装`claude`命令后可以直接用自然语言让AI帮你操作文件系统、运行分析，甚至能通过MCP协议访问你的本地文件，挺科幻的。不过目前需要申请内测。还有OpenAI官方CLI（用`pip install openai`之后可以用`openai api chat_completions`等命令），但比较底层，适合开发者直接调用API做脚本。另外，如果你喜欢本地运行模型，Ollama本身自带的`ollama run`可以在终端里交互式聊天，配合`llm`或者`aichat`使用效果也很棒。

写在最后

别再把终端和AI割裂开了。这些AI命令行工具不仅能帮你快速生成命令、解释错误、写脚本，还能让你在敲键盘的流程里保持专注，不用切换到浏览器和聊天窗口。我个人现在几乎每天都会用到`sgpt`和`gh copilot`，尤其是在折腾服务器配置或者写复杂Shell脚本的时候，效率提升至少一倍。建议你先挑一个顺手的装上试试，比如从`sgpt`开始，感受一下在终端里直接“问”AI的爽快感。用熟了之后，你会发现自己再也回不到手动百度命令的时代了。
