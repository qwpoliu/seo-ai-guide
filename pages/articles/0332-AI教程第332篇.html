为什么选LangChain？

老铁们，如果你用过OpenAI的API，肯定遇到过这个问题：直接调用GPT返回的答案太“死板”，没法结合你自己的知识库，更没法让AI记住上下文。LangChain就是专门解决这个痛点的。它帮你把大模型（比如GPT-4、Claude）和外部数据源（比如你的文档、数据库、网页）串起来，还能轻松实现多轮对话、记忆管理、甚至调用搜索引擎。简单说，有了LangChain，你就能让AI变成“懂你公司业务的专属客服”。

环境准备：三分钟搞定

先别慌，装环境特别简单。打开你的终端，Python版本建议3.9以上。一条命令：

```bash

pip install langchain openai chromadb

```

解释一下：`langchain`是主角，`openai`用来调用大模型，`chromadb`是用来存你知识库的向量数据库。如果你没有OpenAI的Key，也可以用Anthropic、Google或本地开源模型，今天咱们用OpenAI演示。

接下来，把你的OpenAI API Key设置成环境变量：

```bash

export OPENAI_API_KEY="sk-你的key"

```

Windows用户用`set`命令，或者直接在代码里写也行（不推荐）。

核心模块：听懂这些词就够了

LangChain的模块很多，但做问答机器人你只需要掌握三个：

1. LLM（大模型）：就是负责“思考”的引擎，比如`ChatOpenAI`。

2. Vector Store（向量存储）：把你的知识文档（比如PDF、网页内容）切成小块，转成向量存起来。问答时，机器会先检索最相关的几块内容，再交给LLM回答。

3. Chain（链）：把上面两步串起来的管道。你输入问题 → 向量库检索相关文档 → 连问题带文档一起给LLM → LLM输出答案。

听着抽象？别急，下面代码一走你就懂了。

实战代码：十分钟搭建问答机器人

咱们做一个能回答你公司FAQ的机器人。假设你有一个叫`faq.txt`的文本文件，里面是常见的客户问题与答案。咱们先把它加载进来。

```python

from langchain.document_loaders import TextLoader

from langchain.text_splitter import CharacterTextSplitter

from langchain.embeddings import OpenAIEmbeddings

from langchain.vectorstores import Chroma

from langchain.chat_models import ChatOpenAI

from langchain.chains import RetrievalQA

loader = TextLoader("faq.txt")

documents = loader.load()

text_splitter = CharacterTextSplitter(chunk_size=500, chunk_overlap=50)

texts = text_splitter.split_documents(documents)

embeddings = OpenAIEmbeddings()

vectorstore = Chroma.from_documents(texts, embeddings)

llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

qa_chain = RetrievalQA.from_chain_type(

llm=llm,

chain_type="stuff", # 简单模式：把所有检索到的文档塞进prompt

retriever=vectorstore.as_retriever()

)

while True:

query = input("请输入你的问题（输入q退出）：")

if query == "q":

break

result = qa_chain.run(query)

print("🤖 机器人回答：", result)

```

看到没？核心代码就十几行。运行起来后，你问“你们怎么退款？”，机器人会自动从`faq.txt`里找相关片段，然后生成一个完整、口语化的回答。而且因为用了`Chroma`，即使文件很大，检索也是毫秒级的。

进阶技巧：让机器人更聪明

上面的例子是最基础的版本，实际项目中你还需要考虑这些：

  • 多轮对话：用`ConversationRetrievalChain`，加上内存模块，机器人就能记住之前说了什么。
  • 多文件格式：用`UnstructuredFileLoader`支持PDF、Word、Excel甚至图片（配合OCR）。
  • 自定义提示词：你可以调整`prompt`，让机器人的风格更专业或更幽默。
  • 部署成API：用FastAPI包装一下，就能接入你的公众号、网站或企业微信。

比如加上对话记忆的代码就几行：

```python

from langchain.memory import ConversationBufferMemory

memory = ConversationBufferMemory(memory_key="chat_history", return_messages=True)

qa_chain = RetrievalQA.from_chain_type(

llm=llm,

chain_type="stuff",

retriever=vectorstore.as_retriever(),

memory=memory

)

```

这样机器人就会像真人一样，记住你刚才问的问题，比如你问“你们有哪些套餐？”，它回答后，你再问“最便宜的是哪个？”，它就知道你指的是套餐。

踩坑提醒：千万别踩这几个雷

1. 文档太大不切分：LLM的上下文窗口有限（比如4K token），不切分的话直接报错。

2. 温度设置太高：做问答机器人建议`temperature=0`，不然它会自由发挥，编造答案。

3. Key记得保密：别把API Key上传到GitHub，用环境变量或者`.env`文件。
