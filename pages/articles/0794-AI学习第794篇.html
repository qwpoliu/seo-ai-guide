AI学习第794篇

大家好，我是你们的老朋友。今天这篇是AI学习系列的第794篇——别数了，没错，我确实写了快800篇。今天不聊高大上的Transformer，也不谈GPT-4，咱们回到最基础的东西：手写一个最简单的神经网络。为什么？因为基础不牢，地动山摇，很多新手一上来就啃论文，结果把自己噎住了。

神经网络到底是个啥？

说白了，神经网络就是一堆数学公式叠在一起。你给它输入数据，它算一算，输出一个结果。中间那些“层”就像筛子，一层层过滤、提取特征。最简单的例子：你给一张猫的图片，它输出“猫”的概率是0.95。

今天我们只做单层感知机的升级版——一个含有隐藏层的全连接网络。用Python的NumPy实现，不用任何深度学习框架。这样你就能真正理解“前向传播”和“反向传播”在干嘛。

代码实战：从零搭建

先引入工具：

```python

import numpy as np

```

我们模拟一个二分类问题：输入两个特征，输出0或1。比如判断一个点是否在圆的内部。

定义网络结构

  • 输入层：2个神经元（x1, x2）
  • 隐藏层：4个神经元（用ReLU激活）
  • 输出层：1个神经元（用sigmoid激活，输出0~1的概率）

先随机初始化权重和偏置：

```python

def init_network(input_size, hidden_size, output_size):

W1 = np.random.randn(input_size, hidden_size) * 0.01

b1 = np.zeros((1, hidden_size))

W2 = np.random.randn(hidden_size, output_size) * 0.01

b2 = np.zeros((1, output_size))

return W1, b1, W2, b2

```

前向传播——数据怎么流动的

把输入一层层往前算：

```python

def forward(X, W1, b1, W2, b2):

Z1 = np.dot(X, W1) + b1

A1 = np.maximum(0, Z1) # ReLU

Z2 = np.dot(A1, W2) + b2

A2 = 1 / (1 + np.exp(-Z2)) # sigmoid

return A1, A2

```

这里`A2`就是最终预测的概率。比如预测0.8，说明模型觉得有80%可能是类别1。

反向传播——怎么让模型变聪明

关键来了。我们需要计算损失（比如用交叉熵），然后求梯度，更新权重。

损失函数（二分类）：

```python

def compute_loss(y, y_pred):

m = y.shape[0]

loss = -np.mean(y * np.log(y_pred) + (1 - y) * np.log(1 - y_pred))

return loss

```

反向传播的数学推导我直接跳过，给你核心代码：

```python

def backward(X, y, A1, A2, W2):

m = X.shape[0]

dZ2 = A2 - y # 输出层误差

dW2 = np.dot(A1.T, dZ2) / m

db2 = np.sum(dZ2, axis=0, keepdims=True) / m

dA1 = np.dot(dZ2, W2.T)

dZ1 = dA1 * (A1 > 0) # ReLU的导数

dW1 = np.dot(X.T, dZ1) / m

db1 = np.sum(dZ1, axis=0, keepdims=True) / m

return dW1, db1, dW2, db2

```

然后按照学习率更新参数：

```python

def update_params(W1, b1, W2, b2, dW1, db1, dW2, db2, lr=0.01):

W1 -= lr * dW1

b1 -= lr * db1

W2 -= lr * dW2

b2 -= lr * db2

return W1, b1, W2, b2

```

训练循环

来，跑1000次迭代：

```python

X = np.random.randn(100, 2) # 100个样本

y = (X[:, 0]2 + X[:, 1]2 < 1).astype(int).reshape(-1,1) # 圆内为1

W1, b1, W2, b2 = init_network(2, 4, 1)

for i in range(1000):

A1, A2 = forward(X, W1, b1, W2, b2)

loss = compute_loss(y, A2)

dW1, db1, dW2, db2 = backward(X, y, A1, A2, W2)

W1, b1, W2, b2 = update_params(W1, b1, W2, b2, dW1, db1, dW2, db2)

if i % 100 == 0:

print(f"第{i}步，损失：{loss:.4f}")

```

跑完之后，准确率随便一测就90%以上。你看，一个能用的神经网络就这么写出来了。

为什么这么写？背后逻辑你得懂

很多人会问：为什么不用PyTorch？因为用NumPy手写能让你看到每个矩阵乘法的意义。比如`np.dot(X, W1)`就是把输入特征和权重做线性组合，加上偏置后经过非线性激活——这一步就是“特征提取”。而反向传播的梯度下降，本质上是在多维空间里找极小值点。

你学会了这个，再去看深度学习框架的文档，就能理解为什么`torch.nn.Linear`需要输入输出维度，为什么`ReLU`是常见的激活函数。一切都不是黑盒。
