Midjourney教程第803篇

很多玩Midjourney的朋友都有过这样的苦恼：好不容易用咒语生成了一张超帅的角色图，想让他换个场景、换个姿势再来一张，结果出来的完全不是同一个人。要么五官全变，要么气质跑偏，跟换了个演员似的。别急，今天这篇教程就是专门来治这个“角色跑偏”毛病的。第803篇，咱们聊聊怎么用Midjourney的“角色参考”功能，让同一个角色稳定出现在不同画面里。

为什么要用角色参考？

其实Midjourney本身没有“记忆”，每次生成都是独立随机。想让角色长一样，过去全靠调种子号（seed）加上固定的描述词，运气成分很大。后来官方推出了`--cref`（角色参考）参数，相当于给AI一张“证件照”，让它照着这张脸去画。从此，你只用一次出个好图，后面就能让这个角色满世界跑了。

核心参数：--cref 和 --cw 怎么用？

角色参考的语句很简单，在提示词末尾加上`--cref 图片链接`。图片链接可以是你在Midjourney里生成的图，也可以是自己上传的图（需要先把图传到Discord里获得链接）。

举个例子：

```

一个身穿宇航服的青年，在月球表面跳跃 --cref https://你的图片地址.jpg

```

这样生成的图，人脸和整体气质就会尽量贴近参考图。

但光有`--cref`还不够，因为有时候AI会连衣服、背景都照搬，那不是我们想要的。这里就需要另一个参数`--cw`（角色权重），范围0到100。默认是100，表示参考强度最大，连服装、发型、色调都尽量一致。如果你只想保留脸，其他自由发挥，就把`--cw`调低，比如0、20、50。

  • -cw 100：几乎复刻角色，连衣服都相似，适合生成同一套造型的不同角度。
  • -cw 50：保留面部特征，服装可变化，适合让角色换衣服。
  • -cw 0：只保留基础脸型，五官细节可能会变，适合完全换装换背景，但脸不要太离谱。

实战：让动漫少女从咖啡馆走进森林

咱们来走一遍完整流程。先在自己电脑上找一张喜欢的动漫风格角色图，或者用Midjourney先生成一个：

第一步：生成参考图。用提示词 `动漫少女，长发，水手服，正面，半身，柔光 --ar 2:3`，挑一张最满意的，右键复制图片链接。

第二步：让它穿别的衣服。输入：

```

动漫少女，穿着白色连衣裙，在森林里奔跑，阳光透过树叶 --cref 刚才复制的那串链接 --cw 40

```

这里我把cw调到40，希望保持脸的同时，服装和场景自由发挥。你会看到出来的少女脸型、眼睛、发色跟参考图很像，但衣服变成了连衣裙，背景也从室内变成了森林。

第三步：换个更夸张的场景。试试：

```

动漫少女，穿着晚礼服，站在红毯上，闪光灯，人群欢呼 --cref 同一链接 --cw 30

```

看，同一张脸，完全不同的氛围。这才是角色一致性的正确打开方式。

常见翻车 & 解决方法

1. 脸还是不像？ 检查一下参考图是否干净，不要有遮挡、侧脸角度太大。最好用正面或微侧的大头照。另外，`--cw`调高到80-100再试。

2. 背景也被强行复制？ 那是cw太高了，降到30以下，同时在提示词里详细描述新背景，引导AI忽略原图背景。

3. 风格变了（比如写实变动漫）？ `--cref`主要管角色特征，不控制画风。如果你同时想保持风格，可以再加一个`--sref`（风格参考），把两张图的链接都用上。

4. 多角色情况下怎么办？ `--cref`一次只认一个角色。如果画面里有多个人，它会优先把参考图的脸用在最显眼的角色上。可以考虑分两次生成，然后后期合成，或者用`--cref` + `--cw 0`只保留脸型，再通过文字区分其他角色。

两个小贴士

  • 用Midjourney自己的生成图做参考，效果通常比自己上传的图好，因为画风和分辨率匹配。
  • 如果你想让角色一直保持特定表情或动作，可以在提示词里加“同一个人”，不过Midjourney理解不了“同一人”这个词，靠的还是参数。坚持用同一张`--cref`参考图，并且每次用固定的种子号（`--seed 12345`），一致性会更高。

总结

角色参考功能可以说是Midjourney进阶用户必备技能。从今天开始，你不再需要每次从头抽卡，只要有一张满意的角色就能无限复刻到任何场景里。记住三要素：一张好的参考图，合适的`--cw`权重，加上足够具体的场景描述。多试几次，你就能拥有属于你自己的“御用演员”了。
